# برومبتات كتابة النصوص الجاهزة (13 نوعًا)

كل برومبت يطلب من ChatGPT نصًا **بالصيغة الجاهزة تمامًا** لتلصقه في تيليجرام أو تحفظه ملف `.txt` وترفعه.
الأنواع: 4 شورت + 8 طويل + 1 بودكاست = 13.

الاستخدام: انسخ «القالب العام» للنوع الذي تريده (شورت أو طويل أو بودكاست)، ثم أضف تحته «برومت النوع»، واكتب موضوعك في آخره.
النظام لا يعيد صياغة النص ولا يراجعه: ما تكتبه هو ما يُنطق ويظهر. لذلك راجع النص بنفسك قبل الإرسال.

```
نص 1: (الجملة الأولى هي الخطاف، 30 كلمة أو أقل وتنتهي بنقطة أو علامة استفهام، ثم باقي النص 1)
نص 2: ...
نص 3: ...
مشهد 1: english search phrase
مشهد 2: english search phrase
مشهد 3: english search phrase
مشهد 4: english search phrase
مشهد 5: english search phrase
مشهد 6: english search phrase
مشهد 7: english search phrase

القواعد:
- مجموع كلمات النصوص الثلاثة بين 40 و230 كلمة (الأفضل 150 إلى 200).
- المشاهد 1 إلى 3 للنص 1، و4 و5 للنص 2، و6 و7 للنص 3.
- كل مشهد عبارة بحث بالإنجليزية من 3 كلمات فأكثر، تصف لقطة حقيقية بلا وجوه واضحة (أيدٍ، ظهر شخص، غرفة، شارع، ضوء نافذة...). لا تكرر مشهدًا.
- عربية سليمة بسيطة وصادقة، جمل قصيرة، بلا حشو ولا وعظ ولا وعود مبالغ فيها.
- لا تضع علامات تنسيق (لا نجوم ولا عناوين ماركداون).
```

## القالب العام للطويل (الفيلم)

```
اكتب لي نص فيلم وثائقي عربي بالصيغة التالية حرفيًا، بلا أي شرح قبله أو بعده:

فيلم جاهز
عنوان: (120 حرفًا كحد أقصى)
نوع: (واحد من: direct_cinematic / question_answer / inner_dialogue / problem_reveal_solution / story_analysis / paradox / hypothesis_test / connected_list)
دعوة: (اختيارية: جملة واحدة قصيرة بطلب واحد، مثل: شاركنا رأيك في التعليقات.)
نص 1: ...
نص 2: ...
نص 3: ...
نص 4: ...
نص 5: ...

القواعد:
- خمسة فصول بالضبط. النص 1 يبدأ بخطاف قوي في جملته الأولى.
- الطول: حوالي 120 كلمة لكل دقيقة. لفيلم 10 دقائق اكتب نحو 1200 كلمة موزعة على الفصول الخمسة (الحد الأدنى 300 كلمة).
- سرد مباشر بصوت واحد. ممنوع A: و B:.
- لا تكتب افتتاحية القناة ولا الدعاء ولا تعريف القناة ولا الخاتمة؛ النظام يضيفها.
- كل فصل يغيّر الحجة أو يعمّقها، لا يكرر ما قبله. الفصل الأخير يحسم الفكرة.
- عربية سليمة صادقة، بلا حشو ولا وعظ ولا ادعاءات علمية غير مؤكدة.
- لا علامات تنسيق.
```

## القالب العام للبودكاست

```
اكتب لي حلقة حوارية عربية بالصيغة التالية حرفيًا، بلا أي شرح قبلها أو بعدها:

بودكاست جاهز
عنوان: (120 حرفًا كحد أقصى)
غلاف: (اختياري: من كلمة إلى 6 كلمات للغلاف)
دعوة: (اختيارية: جملة واحدة قصيرة بطلب واحد)
A: سؤال المستمع؟
B: الجواب.
A: ...
B: ...

القواعد:
- أول سطر A: وهو سؤال بعلامة استفهام، ويليه B: مباشرة. كل سؤال A: يتبعه جواب B: مباشرة.
- سؤال A قصير (20 كلمة كحد أقصى). كلام A لا يزيد على 35% من الحلقة؛ الأجوبة هي الأساس.
- الطول: 840 كلمة تقريبًا لحلقة 8 دقائق (الحد الأدنى 250 كلمة).
- A هو المستمع الذكي الذي يسأل ويعترض بصدق، وB يجيب بعمق. بلا «مرحبًا بكم» ولا «ضيفنا» ولا مجاملات.
- لا تكتب الدعاء ولا تعريف القناة؛ النظام يضيفها.
- كل جولة تقدّم الحجة خطوة، ولا تكرر السؤال بصيغة أخرى.
- لا علامات تنسيق.
```

# برومبتات الأنواع

أضف برومبت النوع بعد القالب العام، ثم في آخر الرسالة: «الموضوع: ...».

## الشورت (4 أنواع)

### 1) `why_reframe` — لماذا / إعادة التأطير
```
النوع: why_reframe (اكتب «نوع: why_reframe»).
البنية: النص 1 يضرب اعتقادًا خاطئًا يؤمن به المشاهد في جملة الخطاف (مثل: «المشكلة ليست أنك كسول.»). النص 2 يقابله بالواقع ويكشف التناقض. النص 3 يعطي الفهم الجديد كخلاصة واضحة.
معيار الجودة: المشاهد يفهم في الثانية الأولى ما الاعتقاد الذي سيُكسر؛ كل نص يضيف فكرة جديدة؛ النهاية تغيّر نظرته لا تعظه.
تجنّب: الخطاف العام («كلنا نمر بأوقات...»)، وسرد النصائح، وتكرار الفكرة بثلاث صيغ.
مشاهد: 1-3 توتر أو تناقض مرئي، 4-5 نقطة التحول، 6-7 صورة الفهم أو النتيجة.
```

### 2) `inner_dialogue` — الحوار الداخلي
```
النوع: inner_dialogue (اكتب «نوع: inner_dialogue»).
البنية: صوت واحد يتحدث مع نفسه بصيغة المتكلم: ضغط شخصي، ثم احتكاك وسؤال لنفسه، ثم فعل صغير يغيّر الحال («قلت لنفسي... ثم لاحظت...»).
معيار الجودة: شعور حقيقي قابل للتصديق، بلا مبالغة؛ السؤال الداخلي محدد لا عام؛ الانفراج صغير وصادق.
تجنّب: الوعظ، والتحفيز الجاهز، والمصطلحات النفسية الثقيلة، وتشخيص المشاهد.
مشاهد: قريبة وحميمة (يد، نافذة، ضوء ليل، دفتر)، وتنتهي بلقطة انفراج (ضوء النهار، باب مفتوح).
```

### 3) `micro_story` — قصة قصيرة
```
النوع: micro_story (اكتب «نوع: micro_story»).
البنية: النص 1 مشهد محدد (مكان وزمن وفعل)، النص 2 حدث يقلب الوضع، النص 3 المعنى الذي ظهر.
معيار الجودة: تفصيل حسي واحد على الأقل في كل نص؛ الحدث يغيّر شيئًا فعلًا؛ المعنى يخرج من القصة ولا يُلصق بها.
تجنّب: اختراع سيرة ذاتية للمتحدث، والقصة المثالية المصطنعة، والخاتمة الوعظية.
مشاهد: متصلة كقصة (نفس المكان أو الشخص من الخلف)، لا مقاطع عشوائية.
```

### 4) `quote_reflection` — اقتباس وتأمل
```
النوع: quote_reflection (اكتب «نوع: quote_reflection»).
البنية: النص 1 يبدأ باقتباس حقيقي بين علامتي تنصيص مع اسم قائله. النص 2 يتأمل فيه ويفكك معناه. النص 3 يصل إلى خلاصة.
معيار الجودة: الاقتباس صحيح ومنسوب لقائله فعلًا (إن لم تتأكد فلا تستعمله)، والتأمل يضيف ولا يشرح الواضح.
تجنّب: اقتباسات مجهولة المصدر أو منسوبة خطأ، وتكرار الاقتباس.
مشاهد: هادئة وثابتة نسبيًا ثم انفراج في النهاية.
```

## الطويل (8 أنواع)

### 1) `direct_cinematic` — سينمائي مباشر (الافتراضي)
```
النوع: direct_cinematic.
البنية: حجة واحدة متدفقة: توتر فوري ثم فهم يتعمق فصلًا بعد فصل ثم حسم مستحق. ليست قائمة فصول.
معيار الجودة: الجملة الأولى مشهد أو توتر لا تقديم؛ كل فصل ينقل المشاهد إلى فهم أعمق؛ الحسم يرتبط بالافتتاح.
تجنّب: «في هذا الفيديو سنتحدث»، والتكرار، والخاتمة التي تعيد الملخص بحرفه.
```

### 2) `question_answer` — سؤال وجواب
```
النوع: question_answer.
البنية: راوٍ واحد يطرح أسئلة صادقة تزداد عمقًا ويجيب عنها بالتتابع (بلا A: و B:). كل جواب يفتح السؤال التالي.
معيار الجودة: الأسئلة ليست أسئلة الأسئلة الشائعة المسطحة؛ كل جواب يضيف دليلًا أو سياقًا جديدًا؛ آخر سؤال هو أعمق سؤال.
تجنّب: قائمة FAQ، وأسئلة بلاغية بلا جواب، وتكرار «السؤال الآن هو».
```

### 3) `inner_dialogue` — حوار داخلي
```
النوع: inner_dialogue.
البنية: صوت واحد بصيغة المتكلم: احتكاك محسوس ثم سؤال لنفسه ثم تصحيح ثم وضوح مستحق، موزعة على الفصول الخمسة.
معيار الجودة: صدق الشعور، وتدرج حقيقي في الفكرة، وانفراج يغيّر حال الافتتاح.
تجنّب: التحفيز والوعظ، وأن يتحول المتحدث إلى محاضر، وحالة كآبة مستمرة بلا انفراج.
```

### 4) `problem_reveal_solution` — مشكلة ثم كشف ثم حل
```
النوع: problem_reveal_solution.
البنية: فصل أو فصلان لمشكلة محددة بمثال ملموس، ثم الآلية الخفية وراءها، ثم حل عملي واحد مشتق من الآلية. النصيحة تأتي بعد الآلية فقط.
معيار الجودة: المشكلة يتعرف عليها المشاهد من حياته؛ الآلية تفسّر لماذا تفشل الحلول الشائعة؛ الحل واحد وواضح وقابل للتنفيذ.
تجنّب: قائمة نصائح، وادعاءات علمية بلا مصدر، وتضخيم المشكلة لإخافة المشاهد.
```

### 5) `story_analysis` — قصة وتحليل
```
النوع: story_analysis.
البنية: مشهد أو حدث حقيقي ملموس، ثم تغيّر، ثم تحليل لما كشفه، ثم الخلاصة. القصة تستغرق فصلين على الأقل قبل التحليل.
معيار الجودة: القصة كافية لتُصدَّق، والتحليل يكشف ما لم يكن ظاهرًا، والخلاصة تنبع من الحدث.
تجنّب: اختلاق شخصيات تُقدَّم كحقيقية، والقفز السريع إلى المغزى.
```

### 6) `paradox` — مفارقة
```
النوع: paradox.
البنية: تبدأ بتناقض صادق (مثل: «كلما حاولت أكثر، أنجزت أقل»)، ثم تفحص الطرفين، ثم تشرح كيف يصح الاثنان معًا.
معيار الجودة: المفارقة حقيقية لا لعبة لفظية، وكل طرف يُعرض بإنصاف، والحل يزيل التناقض الظاهري.
تجنّب: مفارقات مصطنعة، وحسم مبكر يلغي التوتر.
```

### 7) `hypothesis_test` — اختبار فرضية
```
النوع: hypothesis_test.
البنية: فرضية معقولة («هل فعلًا...؟»)، ثم اختبارها بأدلة وأمثلة يومية، ثم خلاصة بحذر.
معيار الجودة: الفرضية محددة، والأدلة من الحياة اليومية أو من مصادر تذكرها بدقة، والخلاصة تقول ما يصح قوله فقط.
تجنّب: الجزم بالسببية، واختراع أرقام أو دراسات.
```

### 8) `connected_list` — قائمة مترابطة
```
النوع: connected_list.
البنية: أسباب أو علامات أو خطوات متصلة يغيّر كل بند فيها الحجة. خمسة فصول = خمسة بنود (أو بند لكل فصل مع افتتاح في الأول وحسم في الأخير).
معيار الجودة: كل بند يبني على ما قبله ولا يمكن تبديل ترتيبه، والبند الأخير يربط القائمة كلها.
تجنّب: «أولًا ثانيًا ثالثًا» الجاف، ونصائح قابلة للتبديل، وعناوين الإثارة المرقمة.
```

## قائمة فحص قبل الإرسال

- [ ] أول سطر هو `شورت جاهز` أو `فيلم جاهز` أو `بودكاست جاهز`.
- [ ] سطر `نوع:` من الأسماء المدعومة بالإنجليزية (أو احذفه ليأخذ الافتراضي).
- [ ] الشورت: 3 نصوص، 40 إلى 230 كلمة، خطاف ≤ 30 كلمة، 7 مشاهد بالإنجليزية.
- [ ] الفيلم: 5 نصوص، ≥ 300 كلمة، بلا A:/B:.
- [ ] البودكاست: A سؤال بعلامة استفهام ثم B مباشرة، A ≤ 35%.
- [ ] الصور (فيلم وبودكاست): كملفات لا صور مضغوطة؛ «غلاف» في كابشن صورة الغلاف.
- [ ] في الأخير: «تم» ثم «✅ تأكيد الإنتاج».
